# 食记 · 餐食计划

[打开食记](https://yiqi-q.github.io/meal-notebook-pages/)

管理早餐与外卖方案，安排每周三餐。支持直接编辑、备餐小记搜索及整张卡片拖动排序；一套外卖方案可保存多道菜的分享文字和预算。

记录自动保存在当前浏览器。打开或刷新页面后，填入令牌即可先拉取最新记录；修改后点击右上角「同步到 GitHub」直接推送，无需进入设置。两边记录不同时会提示比较，替换前可下载备份。初次打开为空；令牌仅保留在当前页面会话，刷新后需重新填入，也可由密码管理器填入。重要记录请同步或导出备份。

午餐、晚餐可以选早餐方案或外卖方案，也可以自定义名称或留空。周计划保留保存时的方案内容。

此公开仓库仅包含网页发布文件，不包含个人餐食数据、原始工程、测试或令牌。静态版从分享文字提取菜名和价格；不能保证识别仅能在 App 中打开的商品页面。
